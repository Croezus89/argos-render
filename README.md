# argos-render

Maszyny GitHub Actions do pracy studia Argos Studios: rendery, testy i przeglądarki. W tym repo są tylko workflowy; pliki, na których pracują,
są pobierane w trakcie z repo prywatnego, a wyniki wracają od razu do repo prywatnego. Uruchamianie tylko ręczne.

- `render.yml`: rendery Blendera na wielu maszynach naraz.
- `testy.yml`: testy logiki na wielu maszynach naraz (w logu tylko nazwy testów i OK/BŁĄD).
- `safari.yml`: prawdziwe Safari na Macu i Safari w symulatorze iPhone'a (w logu tylko wersje i liczby).

Wszystkie prawa zastrzeżone.
